Python Automation Toolkit

A simple Python automation tool that automatically organizes messy folders.

Problem
Download folders often become cluttered with images, documents, videos, and installers mixed together.

Solution
This script scans a folder and automatically moves files into categorized folders:
- Images
- Videos
- Documents
- Programs
- Archives

How to Use
1. Open organizer.py
2. Change the folder path:
   path = r"C:\Users\YourName\Downloads"

3. Run:
   python organizer.py
